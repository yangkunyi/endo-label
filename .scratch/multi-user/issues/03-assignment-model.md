# multi-user/03 — 任务分配模型

## Question

分配已定大方向：管理员手动指派，一个 Clip 同一时刻只属于一个标注员。本工单定剩余细节：

- Clip 归属的状态：未分配 / 已分配（标注中）/ 已交审……（状态全集与工单 04 协商，本工单只定"归属"这一半：谁能看到哪些 Clip、指派/改派/回收的操作规则。）
- 改派与回收：标注到一半改派给另一人，已有的标签跟人走还是留在 Clip 上？
- 标注员可见范围：只能看到分给自己的 Clip？（当前单机版是看到全部。）
- 管理员自动分配辅助的形态：按每人持有量均衡分配？按 Clip 类型/批次过滤？最小可用即可。

## Answer

- **分配单位 = (Clip, Task type) 二元组**：一个 Clip 的每种 Task type（phase / class / triplet / mask）各自独立分配，可分给不同人、不同时间。起因：实际工作流是先标一种类别，过段时间再标下一类别。
- **归属约束**：一个 (Clip, Task type) 同一时刻至多一个标注员。
- **可见性**：标注员只见自己名下的 (Clip, Task type) 条目；全量列表仅管理员与审阅者可见。
- **改派/回收**：标签物理上跟 Clip 走，分配关系只决定谁可写；回收后标签保留，无"清标签"选项。
- **自动分配辅助**：管理员多选未分配条目 → 按各人当前持有量均衡分配，可按批次/Task type 过滤；速度加权等进阶策略留在地图可选 feature。

术语：`CONTEXT.md` 新增 Assignment 词条；工单 04 的状态单位、05 的写锁粒度、08 的看板行粒度随之改为 (Clip, Task type)。

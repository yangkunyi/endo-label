Four kinds on one Clip

Question: can one Session, on one Clip, hold phase, class (stackable flags: tools, blur, …), triplet, and mask without those kinds stealing each other’s Frame or identity? Phase is stored per Frame; painting a span writes every Frame inside. There is no umbrella word — the state lists the four names.

Free play

Frames — click a cell to scrub (change the current Frame)

Scrub = move along the Clip. Does not Predict. Does not write phase/class/triplet/mask.

phase — paint interval (canonical: one value per Frame)

class — flags on this Frame (stack; click on/off)

Not one exclusive label. Several can be on at once (grasper + blurred). Names are yours to add.

triplet — rows on this Frame (no Track required)

mask — Predict on this Frame; Propagate with SAM (same as current desk)

Fake Predict = stand-in for running SAM on this Frame (points/boxes/scribbles in the real desk). This HTML cannot load the GPU model, so it drops a dummy box on the Active Track. Propagate then fills later empty Frames from that seed. Not a drawing tool.
